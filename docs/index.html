yt_ent

yt_ent is a private tool used by the GetYr creator to upload videos to their own YouTube channel. It uses YouTube API Services (the YouTube Data API) to upload videos, set thumbnails and schedule publishing on the owner's own channel.

This is an internal tool for one user (the channel owner). It is not offered to the public and has no sign-up. By using it, the owner agrees to the YouTube Terms of Service.
