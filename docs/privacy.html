Privacy Policy

yt_ent is used only by the owner of the connected YouTube channel.

Data we access

With the owner's permission (Google OAuth), yt_ent uses the YouTube Data API to upload videos, set thumbnails and read basic channel information for the owner's own channel.

How data is used and stored

Access tokens are stored only as encrypted secrets in the owner's GitHub repository and are used only to upload the owner's videos. No personal data is collected from other people, sold, or shared with anyone.

yt_ent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
