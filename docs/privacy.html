Privacy Policy

Last updated: October 2026

yt_ent is a private tool used only by the owner of the connected YouTube channel (GetYr). This policy explains what data it uses and how it is stored and deleted.

YouTube API Services

yt_ent uses YouTube API Services (the YouTube Data API). By using yt_ent you agree to the YouTube Terms of Service. YouTube is a Google service; see the Google Privacy Policy (https://policies.google.com/privacy).

What data is accessed

  • With the owner's permission (Google OAuth 2.0), yt_ent uploads videos to the owner's own channel, sets their thumbnails and reads basic information about the owner's channel (channel name).
  • It reads public lists of popular/trending YouTube videos (titles, tags, view counts) only to choose a topic for a new video.
  • No personal data of other people is collected. There are no other users.

How data is used

Data is used only to prepare and upload the owner's own videos. It is not sold, shared with third parties, used for advertising, or combined with other data.

Storage and deletion

  • The OAuth access token is stored encrypted as a secret in the owner's GitHub account and is used only to upload the owner's videos.
  • Video IDs of the owner's uploads and short topic notes are kept for at most 30 days (to avoid repeating topics) and then deleted automatically.
  • Trending-video information is used during a run only. Temporary run files are deleted automatically after 3 days.

Revoking access

The owner can revoke yt_ent's access to their Google/YouTube account at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After access is revoked, stored data related to the account is deleted within 7 days. To request deletion at any time, email aravindra915@gmail.com.
